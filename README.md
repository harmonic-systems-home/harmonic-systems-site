# harmonic-systems-site

The published site for [harmonicsystems.com](https://harmonicsystems.com), served by GitHub Pages from `main`.

- `index.html`: the home page
- `postcards/`: Postcards to Fred Wright, 1904–1918
- `FamilyTree/`, `ReunionWeb/`, `Family/`, `Images/`: legacy pages from the original site, kept as they were

Everything in this repository is public. Planning notes live in the private `harmonic-systems-private` repo.
